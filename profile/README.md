## 关于我们

我们是一群热爱技术与创新的开发者，专注于利用 AI 能力构建实用的桌面应用、Web 工具与 AI 技能。从把 Git 仓库变成"代码交易所"，到社区内容的自动聚合；从面向听障用户的音频增强，到可复用的 Agent Skill 集合，我们持续探索 AI 与工程结合的边界。

## 项目一览

### 桌面应用

| 项目 | 描述 | 技术栈 |
|:-----|:-----|:-------|
| [**Code-K**](https://github.com/ChaseToDream/Code-K) | 代码交易所 — 把 Git 仓库当股市可视化，每个文件是"股票"，每次 commit 是 K 线 | Electron + React 19 + lightweight-charts |

### Web 应用

| 项目 | 描述 | 技术栈 |
|:-----|:-----|:-------|
| [**TRAE-Forum**](https://github.com/ChaseToDream/TRAE-Forum) | TRAE 官方中文社区帖子聚合站，三视图 + 分类筛选 + 关键词搜索 + 本地收藏，每 2 小时自动更新 | JavaScript + Python + GitHub Actions |
| [**BassMusic**](https://github.com/ChaseToDream/BassMusic) | 低频音乐增强转换工具，面向听障用户的纯浏览器端音频处理，零服务器依赖 + 实时 A/B 对比 | React + TypeScript + Web Audio API |

### AI 技能

| 项目 | 描述 | 技术栈 |
|:-----|:-----|:-------|
| [**SOLO-Skill**](https://github.com/ChaseToDream/SOLO-Skill) | SOLO 技能创作赛的个人 Skill 集合，16 个独立技能覆盖内容创作、数据分析、部署指引与人格蒸馏等场景 | Markdown + Python |
